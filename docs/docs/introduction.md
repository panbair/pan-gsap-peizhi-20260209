# Introduction

Welcome to Universal Animation Library - the most comprehensive animation library for modern web development.

## What is Universal Animations?

Universal Animation Library provides **184+ professional animations** across **11 versions**:

- 📦 **Dual Engine**: Both CSS and GSAP versions
- 🎨 **Rich Effects**: From basic fades to quantum dimensions
- 🚀 **High Performance**: GPU-accelerated, 60fps guaranteed
- 🔧 **Easy to Use**: Simple API, minimal code
- 📱 **Cross-Framework**: Works with Vue, React, Angular, Svelte
